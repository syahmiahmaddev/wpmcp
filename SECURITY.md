# Security Policy

Security is a core priority for **WP-MCP** as it executes high-privilege site management actions via AI agents and MCP protocols.

---

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a security vulnerability within WP-MCP, please **do NOT open a public issue**.

Instead, report it responsibly:
- **Email:** Contact the maintainer directly or use GitHub's private vulnerability reporting feature on the repository.
- Include a detailed explanation of the vulnerability, step-by-step reproduction instructions, and potential impact.

We will review and respond to reports promptly, and issue security patches in minor/patch releases.
